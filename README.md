# Titanic Survival Analysis

Exploratory data analysis of the Titanic dataset using Python, Pandas and Matplotlib.

## Dataset
train.csv from Kaggle: Titanic - Machine Learning from Disaster.
Download it from kaggle.com/c/titanic/data and place it next to the notebook.

## Findings
- About 38% of passengers survived.
- Women survived much more than men.
- First class passengers had a higher survival rate than third class.
